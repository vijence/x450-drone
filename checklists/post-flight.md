# Post-flight checklist

- [ ] Disarm → disconnect the battery → TX off (last)
- [ ] Motors and ESCs: touch test for heat (note anything abnormal)
- [ ] Battery: resting voltage per cell (BX100); note mAh used
- [ ] Inspect props, arms and printed parts for damage
- [ ] Download the `.bin` log → `logs/YYYY-MM-DD_NN.bin`
- [ ] Fill in the flight log entry; open an issue for every problem found
- [ ] Batteries to storage voltage (3.8 V/cell) if not flying within 2 days
