# Pre-flight checklist

## At home
- [ ] Batteries charged (flight packs + TX); storage bag packed
- [ ] Parameter snapshot committed; version noted in the flight log
- [ ] Flight goal and test card written ([template](../templates/flight-log.md))
- [ ] Weather: wind < 8 m/s, no rain; NOTAMs / restrictions checked

## At the field
- [ ] Airframe: arms tight, no cracks, props undamaged and tight, correct rotation
- [ ] Battery strap secure; XT60 fully seated
- [ ] TX on **before** the aircraft; correct model selected; switches in safe positions
- [ ] Ground station connected; telemetry live
- [ ] GPS: ≥ 12 satellites, HDOP < 1.0, EKF healthy, home position set
- [ ] Compass: heading on the map matches reality
- [ ] Failsafes armed: RC, battery, geofence
- [ ] Area clear; spectators > 30 m; announce "arming"
- [ ] Arm → check idle spin on all 4 motors → take off
